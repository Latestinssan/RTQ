# Verification & Source Traceability

Every security claim in RTQ is backed by a real test, a real source file, and a
specific line of implementation. This page maps each claim to its evidence so
anyone can verify independently.

## Security invariants (I1–I12)

All 12 automated invariants live in a single file and run in CI on every push.

| Invariant | Claim | Source file | Test file |
| --- | --- | --- | --- |
| I1 | Capability must be registered before authorization | `packages/core/src/capability-registry.ts` (class `CapabilityRegistry`, `registerCapability` method) | `tests/invariants/invariants.test.ts` |
| I2 | Authorization ticket is single-use (second redemption fails) | `packages/core/src/ticket-store.ts` (ticket redemption + revocation) | `tests/invariants/invariants.test.ts` |
| I3 | Ticket is bound to exact operation, risk, policy, origin | `packages/core/src/ticket-store.ts` (`boundTo` field validation) | `tests/invariants/invariants.test.ts` |
| I4 | Risk engine is authoritative — caller claims cannot downgrade | `packages/risk/src/index.ts:89-100` (`evaluate` function: `maxRisk(baseLevel, claimedRisk)`) | `tests/invariants/invariants.test.ts` |
| I5 | Policy defaults to deny — no match = denial | `packages/policy/src/index.ts:148` (`defaultMode ?? "deny"`) | `tests/invariants/invariants.test.ts` |
| I6 | HMAC signature is deterministic (same input → same output) | `packages/crypto/src/index.ts` (`hmacSha256`, `canonicalJson`) | `tests/invariants/invariants.test.ts` |
| I7 | Constant-time comparison prevents timing attacks | `packages/crypto/src/index.ts` (`constantTimeEqual`) | `tests/invariants/invariants.test.ts` |
| I8 | Redaction scrubs secret-shaped values from results | `packages/crypto/src/index.ts` (`redact` function) | `tests/invariants/invariants.test.ts` |
| I9 | Sandbox reports `sandboxed: false` when truly unsandboxed | `packages/sandbox/src/index.ts:290` (`sandboxed: true` only when OS confirms) | `tests/invariants/invariants.test.ts` |
| I10 | CLI `capabilities` command lists only registered capabilities | `packages/cli/src/commands/capabilities.ts` | `tests/invariants/invariants.test.ts` |
| I11 | CLI `policy check` returns deny for unregistered operations | `packages/cli/src/commands/policy-check.ts` | `tests/invariants/invariants.test.ts` |
| I12 | Origin field is never spoofable by caller | `packages/core/src/ticket-store.ts` (origin bound at issuance, not from caller) | `tests/invariants/invariants.test.ts` |

## How to verify locally

```sh
# Run all green-scoped tests
npx vitest run tests/{unit,security,fs,sandbox,invariants,cli}

# Run the 12 invariants specifically
npx vitest run tests/invariants

# Build all 10 packages
npx tsc -b packages/{crypto,audit,core,risk,policy,clarification,approval,sandbox,security,cli}

# Run the CLI
RTQ_SIGNING_KEY="$(openssl rand -hex 32)" npx rtq capabilities --config settings/config.js

# Run the example
npx tsx examples/agent.ts
```
